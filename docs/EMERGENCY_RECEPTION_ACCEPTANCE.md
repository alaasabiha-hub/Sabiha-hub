# وضع الطوارئ — نطاق القبول الحالي

القبول المحلي بتاريخ 15 نوفمبر 2026 يخص مسودة وصول أو أولوية لحجز معروف، من شاشة الاستقبال الحالية وبصلاحية المالك أو المدير الحالية. لا يتيح إنشاء عميل أو حجز أو فاتورة أو دفع أو نقاط أو حجز سعة دون اتصال.

## التخزين والمزامنة

- عبارة محلية مستقلة، لا ترسل للخادم ولا تحفظ على الجهاز. فقدانها يمنع فك السجل؛ لا تمسح السجل أو تعيد تهيئته لمعالجة كلمة خاطئة.
- AES-256-GCM مع PBKDF2-HMAC-SHA256 بعدد600000 وsalt/nonce عشوائيين وربط الحساب في AAD. قيمة تخزين مشفرة واحدة، وقفل Web Locks إلزامي بين التبويبات.
- تحفظ علامة بدء الإرسال قبل طلب الخادم. إعادة المحاولة تستخدم UUID والمحتوى الأصليين، بما في ذلك بعد فقدان الرد. لا تلغى مسودة أرسلت ونتيجتها مجهولة.
- التحقق من اتصال الخادم يعتمد على RPC مصرح، وليس حالة اتصال المتصفح وحدها. توقيت الجهاز معلن غير موثق؛ وقت الوصول الرسمي يحدده الخادم.
- صلاحيات الخادم والفرع والمراجعة تظل سارية. تبديل الحساب يقفل المفتاح في الذاكرة ويخفي المسودات السابقة؛ لا ينقل السجل للحساب الجديد.

## أدلة القبول

- عشرة اختبارات تشفير على host Dart VM، وفك مستقل ورفض العبث، واختبار مرجع الحجز، وتسع حالات widget للواجهة وأربع حالات parent متأثرة. هذه ليست اختبارات Android/iOS.
- Chrome حقيقي: العربية والإنجليزية بعرض390 و1440، بعد تحميل التطبيق: انقطاع شبكة ثم حفظ مشفر ثم عودة الشبكة وإرسال للخادم وحفظ الإقرار.
- فقدان رد بعد commit وإعادة نفس الطلب: سجل استقبال وطلب وتدقيق واحد فقط. فك storageState الفعلي مستقلًا أثبت الحالة confirmed والمحتوى الأصلي لكل الحالات الأربع.
- تبويبان يتنافسان خلف قفل فعلي: احتفظت الوثيقة المشفرة بمسودتين مختلفتين دون فقد تحديث أو إرسال كتابة خادم.
- البيانات في QA معزولة فقط. ألغيت الحجوزات الستة واحتفظ بتاريخها، وعطلت الخدمة والفرع الاختباريين. لم تنشأ فواتير أو مدفوعات. الصفوف السابقة محفوظة عدا زيادة عداد الحجز المتوقعة.

## غير معتمد بعد

تشغيل Web البارد دون إنترنت، وإخلاء المتصفح أو فقد التخزين، والتشغيل على Android/iOS، والاستقبال الجديد دون حجز، والتكامل النهائي لكل رحلات الخدمة. اكتمال هذه الشريحة لا يعني اكتمال وضع الطوارئ الشامل أو المشروع. اختبار الطابعات الحقيقية مؤجل للمراجعة النهائية.

الأدلة المحلية الخاصة لا ترفع إلى المستودع؛ جلسات QA وstorageState والجورنالات تحفظ بصلاحيات خاصة وضمن النسخة الاحتياطية المشفرة.
